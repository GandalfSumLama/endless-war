# Журнал изменений Endless War

Каждая правка записывается сюда: дата, версия, кто правил и что изменилось.
Текущая версия и дата показываются в игре: Настройки → строка внизу (`js/version.js`).

**Как добавить запись (для всех, кто правит проект):**
1. Подними версию и дату в `js/version.js` (`GAME_VERSION`, `GAME_UPDATED`).
2. Добавь сверху раздел `## <версия> — <ГГГГ-ММ-ДД>`, под ним жирным — кто правил, дальше пункты: что изменилось и в каких файлах.
3. Пароли, ключи и прочие секреты сюда не пишем.
4. Для APK передай ту же версию в сборку: `android/build.ps1 -VersionCode <число больше прошлого> -VersionName <версия>`.

## 0.3.10 — 2026-10-03
**Claude** — вибрация в Telegram
- В Telegram вибрация не работала.
  - Когда игру открывает галерея, параметры запуска Telegram теряются. Тогда `TG` пустой, а `navigator.vibrate` внутри Telegram ничего не делает.
  - Если параметры частично есть, `HapticFeedback` из SDK молча отказывается работать: без версии Telegram он считает её 6.0.
- Теперь команда вибрации `web_app_trigger_haptic_feedback` идёт напрямую клиенту Telegram через `TelegramWebviewProxy`, так же делает сам SDK. Запасной путь — `HapticFeedback`, внутри Telegram Web — сообщение родительскому окну (`tgHaptic` в `js/core.js`).
- Удары в Telegram на ступень сильнее: «лёгкий» удар Telegram на Android почти не ощущается (7 мс на четверти силы), поэтому light → medium, medium/heavy → heavy. Уведомления (уровень, эволюция, смерть) — как были.
- В APK и браузере вибрация работает как раньше; APK пересобирать не нужно.

Дроны висят дугой за спиной героя и не закрывают его, отбрасывают тень, разворачиваются к цели и стреляют очередью — пули-трассеры. Рой дронов — с бирюзовым свечением и бирюзовыми трассерами (`WB.drone`).

## 0.3.0 — 2026-09-29 (ночь)
**Правки безопасности (не Claude)**
- `android/build.ps1`: пароль ключа подписи больше не хранится в скрипте, берётся из переменной окружения `EW_KEY_PASSWORD` (путь к ключу — `EW_KEYSTORE`, алиас — `EW_KEY_ALIAS`). Версия APK задаётся параметрами `-VersionCode` / `-VersionName`.
- `serve.ps1`: локальный сервер отдаёт только файлы внутри папки игры, слушает только localhost, без кеша.
- `index.html`: скрипт Telegram подключается асинхронно, без `document.write`; `core.js` считает, что игра в Telegram, только при наличии настоящих данных запуска (`initData`).
- Новый `js/dev-checks.js`: `runSmokeChecks()` — проверка данных оружия, эволюций, анимаций, уровней и (с `{ resources: true }`) наличия всех файлов арта. В игру не подключается, только для разработки.
